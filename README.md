# 🎄 Deadlock Christmas — Winter Midtown

Turns Midtown into a winter city: snowy streets and rooftops, frosted foliage, falling snow and festive decorations.

**[⬇ Download from Releases](../../releases/latest)**

## Features
- **Winter map:** snow on asphalt, cobblestone, concrete and brick, snow drifts on rooftops, snowy ledges, frosted bushes and trees, winter sky.
- **Local snowfall:** falls only while you're outside and stops under roofs and indoors. Each player sees snow only around themselves, so performance cost is minimal.
- **Owls instead of crates:** 4 owl variants with debris and a snow burst when broken. Collision matches the original crates.
- **Garlands on bosses:** Mid Boss, Archmother and Hidden King are wrapped in warm yellow string lights that glow and blink. The King has a separate garland for each phase, and the Mid Boss's eye stays uncovered.
- **Santa hats on heroes** (main version only).

## Versions
- `deadlock_christmas_v12_pak01_dir.vpk`: full version with Santa hats.
- `deadlock_christmas_v12_NO_HATS_pak01_dir.vpk`: no hats, all heroes keep their original models. Use this one if you run hero model swap mods.

## Installation
1. Close Deadlock.
2. Rename the downloaded file to `pak01_dir.vpk`.
3. Put it into `Steam\steamapps\common\Deadlock\game\citadel\addons` and confirm replacing.
4. Launch the game.

Install only one version. To uninstall, restore your previous `pak01_dir.vpk`.

## 🇷🇺 Описание

Превращает Midtown в зимний город: снег на улицах и крышах, заснеженная зелень, снегопад и новогодние украшения.

- **Зимняя карта:** снег на асфальте, брусчатке, бетоне и кирпиче, сугробы на крышах, снег на карнизах, заиндевевшие кусты и деревья, зимнее небо.
- **Снегопад вокруг игрока:** идёт только на улице и пропадает под крышей и в помещениях. Каждый видит снег только вокруг себя, поэтому нагрузка минимальная.
- **Совы вместо ящиков:** 4 вида сов, обломки и снег при разрушении. Коллизия как у оригинальных ящиков.
- **Гирлянды на боссах:** мид-босс, Архиматерь и Король обмотаны тёплыми жёлтыми гирляндами, лампочки светятся и мигают. У Короля своя гирлянда для каждой фазы. Глаз мид-босса гирлянда не закрывает.
- **Новогодние шапки на героях** (только в основной версии). Версия `NO_HATS` — без шапок, для тех, кто ставит моды на модели героев.

**Установка:** закрой Deadlock, переименуй скачанный файл в `pak01_dir.vpk`, положи его в `Steam\steamapps\common\Deadlock\game\citadel\addons` с заменой и запусти игру. Ставь только одну версию.
